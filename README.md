1. Download/Clone the repository
2. Run `npm install`
3. Run `npm run build`, which will create a `dist` folder
4. Load the folder to Chrome Extensions & `Load unpacked`
5. Create/Copy your Gemini API key (Create using AI studio) to `Extension Options`
6. Debug is possible under developer mode with `Service Worker`
> You should be able to see `Background script loaded.` in the Dev Tools.
